# 🧱 Tiles Product App

A modern tile showcase web application built with React/Next.js. This project displays different types of tiles with detailed information, helping users explore and choose suitable tiles for their space.

## ⚙️ Installation & Setup

Follow these steps to run the project locally:

```bash
# Clone the repository
git clone https://github.com/anujpaul27/Assignment-8.git

# Navigate to project folder
cd Assignment-8

# Install dependencies
npm install

# Run the development server
npm run dev


```
